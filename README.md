# TechWorld — Electronics & Gadgets

A complete responsive frontend-only ecommerce website built from the supplied TechWorld internship screenshots/specification.

## Included
- Home page with hero, categories, featured products and sale banner
- Product listing with search, category, brand, price and rating filters
- Product detail page
- Shopping cart with quantity adjustment and totals
- Checkout form with payment-method simulation
- User account + order history
- Login / Logout
- Create New Account / Register
- Wishlist
- About Us and Contact Us
- Responsive desktop/tablet/mobile layout
- JavaScript localStorage for cart, user, wishlist and orders
- No database or backend required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Demo authentication
This is intentionally frontend-only. Accounts and orders are stored in browser localStorage and passwords are NOT secure. Do not use real credentials.

## Technology
HTML5, CSS3, vanilla JavaScript. Font Awesome and Google Fonts are loaded from CDNs when internet access is available.
